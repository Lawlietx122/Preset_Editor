# Preset Editor для Android

Нативное приложение на Kotlin и Jetpack Compose. Формат пресетов совместим с SillyTavern и с ПК-версией Preset Editor.

## Что есть в версии 0.2

- Библиотека пресетов: поиск, фильтр по статусу, обложки, импорт JSON, сохранение в файл, «Поделиться», дублирование и удаление (копия удалённого пресета остаётся в `Backups`).
- Список промптов: включение и выключение, перетаскивание за ручку, поиск по имени и тексту, разделы вида `=== Стиль ===`, дублирование, «в начало» и «в конец», удаление.
- Редактор промпта: название, роль, текст с полноэкранным режимом и счётчиком, позиция вставки, глубина, порядок, маркер, просмотр технических полей.
- Вкладка «Инфо»: обложка, название, статус, автор, ссылка, теги и описание.
- Отмена последних действий, автосохранение (в том числе при сворачивании приложения).
- Открытие JSON из других приложений через «Открыть с помощью» и «Поделиться».

## Хранение

Данные лежат во внутренней памяти приложения в той же структуре, что и рабочая папка ПК-версии: `Presets/`, `Metadata/`, `Assets/Covers/`, `Backups/`. Неизвестные поля пресета и метаданных сохраняются как есть, поэтому файл после правки на телефоне можно спокойно открыть на ПК.

## Сборка

APK собирает GitHub Actions (`.github/workflows/android.yml`) при каждом изменении в `android/`. Файл лежит в артефакте `PresetEditor-android` на странице запуска.

Локально нужен Android Studio или Android SDK и JDK 17:

```bash
cd android
./gradlew assembleDebug
```

Для подписанной сборки CI берёт секреты `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS` и `ANDROID_KEY_PASSWORD`. Без них получается debug-APK. Ключ должен оставаться одним и тем же, иначе обновление не встанет поверх старой версии, а удаление приложения сотрёт пресеты в нём.
